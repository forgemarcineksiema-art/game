# Cinder Harbor World-Art Mesh/Material Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Cinder Harbor's primary terrain/road placeholder presentation with a first stronger authored mesh/material pass while keeping `data/worlds/veyra_reach` as source of truth.

**Architecture:** World and area JSON remain authoritative. `tools/world_author.py` compiles those sources into `data/scenes/veyra_reach_pilot.scene.json`, and the generated scene keeps visual placeholders as validation/collision/readability underlay while primary terrain/road/coastal art is expressed as mesh instances with replacement links and material keys.

**Tech Stack:** Python world tooling/tests, deterministic JSON compiler, project-original embedded glTF assets generated by `tools/create_simple_prop_gltf.py`, existing C++ scene loader/render path, existing validation/capture scripts.
