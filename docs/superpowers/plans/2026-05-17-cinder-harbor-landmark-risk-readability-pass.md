# Cinder Harbor Landmark/Risk Readability Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the next runtime-visible Veyra Reach world foundation layer: stronger industrial landmark silhouettes, overlook/relay/cargo-site readability, and route-facing visual anchors sourced from `data/worlds/veyra_reach`.

**Architecture:** `data/worlds/veyra_reach/world.json` and `data/worlds/veyra_reach/areas/cinder_harbor.area.json` remain the source of truth. `tools/world_author.py` validates a new area-level readability pass, compiles the authored mesh instances into `data/scenes/veyra_reach_pilot.scene.json`, and exposes the pass in preview/report output for drift-resistant iteration.

**Tech Stack:** Python authoring tools/tests, deterministic JSON compiler, project-original embedded glTF generated by `tools/create_simple_prop_gltf.py`, existing C++ scene loader/presentation path, existing GDI capture and runtime smoke tools.
